# Pizza Menu

A simple React application that displays a restaurant menu with pizza details, ingredients, and prices.

## Features

- Display a list of available pizzas
- Show pizza names, ingredients, and prices
- Indicate whether a pizza is sold out
- Dynamic rendering using React components
- Component-based architecture
- Clean and responsive user interface
- Conditional rendering for different menu states
- Reusable React components
- Modern JavaScript (ES6+) implementation

## Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## Installation

```bash
npm install
npm start
```
